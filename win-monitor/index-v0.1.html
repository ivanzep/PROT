win-monitor log viewer

Reads the local activity log and shows where focus went — and when the machine was left alone.

Log files

Drop activity-*.jsonl or .csv here,
or click to choose files

Written by win-monitor.ps1, one file per day, in %LOCALAPPDATA%\win-monitor unless you pointed it elsewhere. Load latest log asks you to pick that folder once (a browser can't read it on its own), then loads only the newest activity-*.jsonl file in it - skip hunting for today's file by hand. Chromium-based browsers only.

Filters

←/→ move the whole range by its own length - a day at a time for a single day, a week at a time for a week, etc.

Collapses same app/file/title sessions whose start lands within this many milliseconds of the previous one's end - the signature of two win-monitor.ps1 instances logging the same focus event to the same file. Merges into one session spanning the earliest start to the latest end.
