# XV Años · Kyara — website

Open `index.html` in a browser, or upload this entire folder to GitHub Pages / a static web host.

## Graphic layers
The five WebP files in `assets/` are independently clipped, alpha-blended decorative elements extracted from the supplied invitation image. The arch border and snowflake/icons are separate scalable SVG elements defined in `index.html`; all invitation text is actual HTML rather than baked into a background image. For longer pages, duplicate or reposition `.floral` layers in `index.html` and `styles.css`.

## Buttons
- **Ver en mapa** links to Google Maps **search results** for Jardín Blanc, Zona Río, Tijuana (the exact Google Maps place ID has not been verified).
- **Confirma tu asistencia** opens `confirmacion.html`, a separate functional *demo page*. It does not send or store responses on a server. Replace its form with your preferred live RSVP backend before publishing, or set the button link to your final external confirmation website.

## Other features
Responsive desktop/mobile, subtle scroll reveal, floating floral parallax, smooth anchor scrolling, reduced-motion accessibility, visible focus indicators, semantic sections, and print styles.
