# XV-invite-2 · Kyara

Independent invitation website for Kyara's XV Años, December 19, 2026.

## Files
- `index.html`: responsive invitation with animated layered graphics and linked buttons.
- `confirmacion.html`: demonstration RSVP form; shares/copies confirmation but does not submit to a backend.
- `assets/`: five original, standalone editable SVG botanical compositions created for this folder:
  - `floral-top-left.svg`
  - `floral-mid-right.svg`
  - `floral-bottom-right.svg`
  - `floral-mid-left.svg`
  - `floral-bottom-left.svg`

These SVGs are newly recreated illustrations, **not pixel-identical** to the earlier isolated WebP artwork. The invitation no longer references assets in `xv-invite`.
